Posting workflow with hugo, github and Obsidian

September 9, 2026

So I wanted to start a blog page…#

As everyone does, I first searched on Google “post blog ultra fast github free”. I stumbled on Hugo and really loved the variety of themes one could install, etc.

The Setup itself was not quite hard:#

  • Setting up 2 repos:
    • A repo where you would draft and demo your page
    • A .github.io repo where it would actually be deployed
  • Creating a new Hugo project in the draft repo and choosing a theme
  • Setting up a submodule pub that would refer to the github.io repo and deploying the final build with hugo -t theme -d pub

OK, we got the really basic Hugo-GitHub setup, now how do we make it more quirky with Obsidian?#

Since Hugo and literally any other blog posting framework use .md, I decided to use my beloved tool Obsidian, which I’ve used for 1+ years for high school, uni, and personal learning.

  • I used the /content folder of my Hugo project as a “new” vault

With that, I could use my usual Obsidian setup by copying the .obsidian config folder to the /content folder and use it as if it were my usual note-taking environment.

How does it work now?#

It is an quite easy work-flow:

flowchart TD
    A[Create post.md] --> B[Edit in Obsidian]
    B --> C[Test live demo on localhost]
    C --> D{Refine?}
    D -- Yes,It's terrible! --> B
    D -- Done --> E[Build site into submodule folder]
    E --> F[Commit changes with Git]

Voilà, we have a new blog entry!

Obviously, it doesn’t have to be Obsidian as the Markdown editor of choice, but for people who want to have a nice UI for their editing process like myself, it is really a comfortable experience.

Does it cost anything?#

Nope. GitHub Pages, Hugo, and Obsidian are completely free to use. There are some limitations regarding commercial use, but for non-commercial use, they are completely free.

Damn, it sounds quite difficult!#

  • The hardest part is the initial setup process, but there are some awesome guides out there (for example this guide)!
  • Also, if you want to customize a little bit and add your own flair to your blog page, you will have to read some wikis of your theme/Hugo (it is fun though ;D).

Other than those two hurdles, you could follow my workflow-deploy cycle and have a cozy workflow or make your own workflow-deploy cycle that makes sense to you!

It is better to start with a shitty page, than not starting at all!
