Posting workflow with hugo, github and Obsidian

September 9, 2026

So I wanted to start a blog posting page…#

As everyone does, I first searched on google “post blog ultra fast github free”. I stumbled on Hugo and really loved the variety of themes one could Install ect.

The Setup itself was not quite hard:#

  • Setting up 2 Repos
    • A repo where you would draft and demo your page
    • .github.io repo where it would actually be deployed
  • Starting a new Hugo Project in the draft repo and setting up a theme
  • Setting up an submodule pub that would refer to the github.io repo and deploying final build with hugo -t theme -d pub

OK we got the really basic Hugo-GitHub setup, now how do we it more quirky with Obsidian#

Since hugo and literally any other blog posting frameworks use .MD, I decided to use my beloved tool Obsidian which I’ve used for 1+ year for High-School, Uni and Personal Learning.

  • I made an new vault in the /content folder of my hugo project

With that I’ve could use my usual obsidian setup by copying the .obsidian config folder to the /content folder and use it as if it were my usual Note-Taking enviroment.
